Privacy Policy

Last updated: October 18, 2026

This page describes how the current Umbra Discord bot starter handles information when you use its commands and interactive features. Discord also processes information under its own privacy policy and platform terms.

Information involved

When you use a bot command or component, Discord provides interaction details the bot needs to respond. Depending on the feature, this can include your Discord user ID and account information such as display name, avatar, mention, bot-account status, and account creation date. The profile command uses some of these details to build a profile card.

If you submit the feedback form, its subject and message are handled as part of the Discord interaction. In the current code, the bot replies privately with a confirmation containing what you submitted; the feedback is not forwarded to an operator by that code.

Discord necessarily processes your account, server, and interaction information to provide the platform and deliver bot interactions. Discord's handling is governed by Discord's own policies.

How information is used

The bot uses interaction and profile details to provide the requested command, display profile and panel content, and respond to feedback submissions. The current bot code does not use analytics or advertising features.

Website analytics

The website homepage includes a Cloudflare Web Analytics beacon. When you visit the website, Cloudflare may process visitor and usage information through this service under its privacy policy. This website analytics beacon is separate from the Discord bot; the current bot code does not include analytics.

Storage and retention

The current bot code does not write user information or feedback to a persistent application database. Some temporary component state, such as the user ID used to restrict profile buttons, is held in memory while the component is active; these views time out after five minutes. This does not control what Discord or the bot's hosting provider may process or retain under their own policies. A deployment or later version may differ from this starter code.

Sharing

Bot interactions necessarily pass through Discord. The bot also runs on infrastructure provided by its operator or hosting provider, which may process information as needed to operate the service. The current code does not send feedback to a separate analytics or advertising service. Discord and providers have their own terms and privacy practices.

Your choices

You can choose not to use the bot or submit feedback. If you want to remove content you posted in Discord, you can delete the relevant message or contact the server's staff where appropriate. Deleting a message does not necessarily remove records held by Discord or others, and legal or operational requirements may affect retention. The bot does not provide an automated data-deletion workflow.

Security

Reasonable safeguards depend on how the bot is configured and hosted. No online service or transmission can be guaranteed completely secure, and this starter code does not make a guarantee about the security practices of a particular deployment.

Minors

Use Discord and the bot only if you are permitted to do so under Discord's age requirements and applicable law. The bot is not designed specifically for children.

Changes to this policy

This policy may be updated when the bot or its deployment changes. The date above indicates when this page was most recently revised. Please review it from time to time.

Questions

For questions or support, visit the Umbra Discord server.
